# CSK 3/4" lockbolt — forging die

Shop model for the first blow on a Bolton **CSK 24-XG** countersunk lockbolt: a **150 mm** carbon-steel pin (inside the ERSCSK24-32G length window) headed in a closed die on a **300 tonne** hydraulic press.

The die forms the 100° countersunk head and a plain shank. Lock grooves, the breakneck, and the pintail are a later rolling operation.

## Run

```bash
npm install
npm run dev
```

Open the local URL printed by Next.js (this project uses port 4317 when started with `-p 4317`).

## What the screen shows

- Sectioned punch and lower bush, with the ram stroke from billet load to dwell
- Catalog envelope used for the model (shank, head, length, grip)
- Billet size, die bore, H13 inserts, and the working load versus 300 t
- A dimensioned die section and the press sequence

Figures are a process design from the catalog envelope, not a certified tool drawing. Confirm flow stress, shrink, and press daylight on the actual 300 t machine before cutting inserts.
